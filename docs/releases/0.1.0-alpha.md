# MIRulesets 0.1.0-alpha

Первый предварительный выпуск сервера для сборки и публикации наборов правил Mihomo и sing-box. Веб-панель, шрифты, логотип и CLI встроены в один бинарный файл. Для запуска не нужны Go, Node.js, Python или установленное ядро прокси.

Тег выпуска — `v0.1.0-alpha`; команда `mirulesets version` и API возвращают `0.1.0-alpha`.

## Возможности

| Область | Состав выпуска |
| --- | --- |
| Источники | HTTP(S), S3, `ruleset://`, приватные заголовки, regex-фильтры, ASN → CIDR, статусы загрузки каждого источника |
| Правила | YAML, text, MRS, geosite/geoip DAT, hosts, DNS-подмножество Adblock, sing-box JSON; свои правила, нормализация и точечные исключения |
| Публикация | YAML, text, MRS, sing-box JSON и SRS; расписание, постоянные ссылки, локальные поколения, S3 и повтор только неуспешных форматов |
| Надёжность | Порог падения числа правил, diff, откат с удержанием, восстановление повреждённых локальных поколений, очередь удаления объектов S3 |
| Управление | Общий YAML для Mihomo, проверка домена/IP, счётчики скачиваний, клонирование, поиск и теги, импорт/экспорт, декларативный YAML, метрики и webhook |

Панель поддерживает светлую, тёмную и системную темы. Логотип используется на экране входа, в навигации и как favicon; файл SVG включён без изменений. Проверка источника с ответом `304` сохраняет время последней загрузки тела и отдельно обновляет время проверки.

## Поведение перед публикацией

1. Порог падения сравнивает число правил при неизменной конфигурации. Ровно порог допускается; превышение оставляет клиентам прежнюю сборку. После изменения настроек следующая сборка допускает сокращение правил.
2. Если предыдущее локальное поколение потеряно или повреждено, успешная сборка создаёт новое; недоступный diff сопровождается предупреждением.
3. Откат удерживается до возобновления обновлений, ручной сборки или изменения конфигурации. Повторы отправки в S3 продолжают работать.
4. Недоступность S3 при запуске не останавливает локальный сервер. Ошибки публикации видны в панели; неуспешные форматы отправляются повторно с задержкой.
5. Отдельный `MI_METRICS_TOKEN` разрешает только чтение `/metrics`. Он не даёт доступа к административному API.

## Архивы

| Платформа | Архитектуры | Имена архивов |
| --- | --- | --- |
| Linux | amd64, arm64 | `mirulesets_v0.1.0-alpha_linux_<arch>.tar.gz` |
| macOS | amd64, arm64 | `mirulesets_v0.1.0-alpha_darwin_<arch>.tar.gz` |
| Windows | amd64, arm64 | `mirulesets_v0.1.0-alpha_windows_<arch>.zip` |

`SHA256SUMS` содержит контрольные суммы архивов. Проверка в Linux: `sha256sum -c SHA256SUMS`; в macOS: `shasum -a 256 -c SHA256SUMS`. В PowerShell сравните результат `Get-FileHash <архив> -Algorithm SHA256` со строкой этого архива в `SHA256SUMS`.

После распаковки запустите `./mirulesets` или `.\mirulesets.exe` в PowerShell. Откройте `http://127.0.0.1:8080`; пароль при первом запуске записывается в `data/admin-password`. Другой каталог задаётся через `MI_DATA_DIR`, пароль — через `MI_ADMIN_PASSWORD` или `MI_ADMIN_PASSWORD_FILE`. [Полная инструкция запуска](../deployment.md#бинарник-и-systemd).

Workflow по тегу собирает те же шесть архивов и образ `ghcr.io/blagodaren/mirulesets:0.1.0-alpha` для Linux amd64/arm64. Тег с суффиксом `alpha` публикуется как prerelease. ## Ограничения

1. **Предварительный выпуск.** Перед заменой установки остановите сервер и скопируйте весь каталог данных. Экспорт из UI не содержит секретов и истории. Несколько процессов не должны использовать общий каталог данных.
2. **Форматы сохраняют смысл правил.** MRS не поддерживает `classical`; несовместимые условия sing-box отклоняются. Adblock ограничен доменным DNS-подмножеством. Предпросмотр по URL работает с `auto`, YAML, text и MRS, без пользовательских заголовков и фильтров источника.
3. **Публикация S3 неатомарна.** Локальные файлы переключаются целым поколением; отдельные объекты S3 могут кратковременно принадлежать разным поколениям. Публичные ссылки на файлы не защищены паролем панели.
4. **Счётчики и поиск имеют границы.** Скачивания обнуляются при перезапуске и не учитывают прямой S3/CDN-трафик. Поиск адреса не выполняет DNS-запросы и не оценивает условия, которым нужны данные о процессе или соединении.
5. **Внешняя инфраструктура проверяется отдельно.** Доступность домена и ACME, права настоящего S3-аккаунта, Docker и публикация в GitHub/GHCR требуют проверки в среде развёртывания. ASN использует наблюдаемые BGP-префиксы RIPEstat, а не гарантированно полный список сетей владельца.

## Проверка сборки

```sh
go test ./...
go vet ./...
node --check web/app.js
```

В Linux CI дополнительно выполняется `go test -race ./...`. Тесты кодеков поддерживают сверку с официальными Mihomo и sing-box: [порядок и ограничения проверок](../../internal/rules/README.md). Команды выше предназначены для исходников; Node.js нужен только для проверки JavaScript при разработке.
