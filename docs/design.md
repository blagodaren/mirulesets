# Направление интерфейса

Откройте веб-панель и создайте набор: интерфейс показывает настоящие данные сервера, а при первом запуске — пустое состояние.

Боковая навигация содержит один пункт «Наборы правил». Инструменты доступны со страницы наборов. Инструкции установки и настройки сервера находятся в разделе «Развёртывание» в README; отдельного экрана для них нет. Состояние подключения S3 остаётся в сводке публикации. Неактуальные адреса экранов переводятся на список наборов.

Визуальная основа согласована с [UI kit MIBoard](https://github.com/blagodaren/miboard/blob/main/UI_KIT.md): светлые нейтральные поверхности или тёмный графит, янтарный акцент, локальные Geist и Geist Mono. Поля отличаются от панелей фоном и контрастной границей; заголовки таблиц имеют отдельную поверхность. Боковая панель и порядок разделов сохранены.

Тема переключается в верхней панели и на экране входа. Доступны светлый, тёмный и системный режимы; по умолчанию используется настройка ОС. Выбор хранится локально в браузере и синхронизируется между вкладками. Палитра применяется до загрузки основного интерфейса, а переключение не перерисовывает редактор и не сбрасывает черновик.

Проверка тем: светлый режим сохраняется после перезагрузки; стрелки клавиатуры меняют выбранный режим с видимым фокусом. Переключение из второй вкладки сохраняет открытый редактор и введённое название. Возврат в системный режим убирает явный выбор и применяет текущую тёмную тему ОС. На 390 px все три цели переключателя имеют размер 44 × 44 px; светлый предпросмотр показывает 21 правило в блоке высотой 320 px без горизонтального переполнения. Консоль без ошибок и предупреждений; семь проверок `web/theme_test.cjs` проходят. Переключение самой темы ОС во время проверки не выполнялось.

| Решение | Реализация |
| --- | --- |
| Продукт | Управление источниками, своими правилами и файлами для Mihomo |
| Характер | Точный, спокойный, технический |
| Среда | Серверная панель с нейтральными поверхностями |
| Цветовой акцент | Янтарный для выбора, ссылок и MRS; зелёный только для успешного состояния |
| Повторяющаяся деталь | Behavior и форматы рядом с каждым набором |

Принятые правила: сетка отступов 4 px; графитовая палитра с одним акцентом; единый набор контурных SVG; русские подписи без рекламных обещаний; локальные шрифты и моноширинные данные; боковая навигация и таблица; согласованные размеры контролов; представление реального процесса сборки; короткие переходы и поддержка reduced motion. Декоративных иллюстраций нет: интерфейс показывает только рабочие данные.

Токены, компоненты и правила правок: [UI_KIT.md](../UI_KIT.md).

Уточнения интерфейса касаются плотности форм, коротких предметных подписей, единого представления метаданных и видимых состояний запросов. Числа изменений сопровождаются указанием сравниваемой сборки. Условия предпросмотра объясняются рядом с его кнопкой; ошибки публикации должны оставаться видимыми и после завершения запроса. На узком экране поля и действия сохраняют порядок чтения и не выходят за ширину панели.

Источники добавляются пользователем через «По ссылке»; встроенного каталога нет. В редакторе у каждого источника доступен «Предпросмотр». Он читает текущие URL, формат и behavior. Результат показывает метаданные моноширинным шрифтом и до 200 правил в блоке с прокруткой высотой не более 320 px. Ошибка отображается на том же месте; во время загрузки кнопка недоступна. Проверка источника не сохраняет набор и не добавляет событий.

Примеры и снимки ручных проверок находятся только в игнорируемом `.dev-data`; обычный запуск создаёт пустое пространство.

Проверка 12 ноября 2026 выполнена в отдельном каталоге данных: источник MRS по URL дал 21 правило, затем добавлено своё правило `+.mirulesets-check.example`. Сохранение и ручная сборка создали MRS из 22 правил размером 305 Б. Обратное чтение опубликованного файла через CLI подтвердило число правил и наличие своей записи; поиск адреса в панели нашёл её. Повторная сборка сохранила файл без изменений.

Проверены вход, список, редактор, предпросмотр, карточка публикации, форма копирования набора и инструменты. На ширинах 1440 и 390 px горизонтального переполнения страницы нет; таблица прокручивается внутри панели, предпросмотр ограничен 320 px. В инструментах одна основная кнопка. Консоль браузера без ошибок и предупреждений. Частичная ошибка S3 проверена моделированием ответа: локальный успех не скрывает ошибку публикации.

После переноса визуальной основы MIBoard повторно проверены вход, список, редактор, карточка готового MRS и инструменты. На 1440 px счётчик фильтра остаётся в одной строке. На 390 px поле URL и кнопка предпросмотра имеют высоту 44 px; карточка и код не выходят за экран. Предпросмотр показывает 21 правило; неверный тип `ipcidr` для этого MRS выводит ошибку на месте результата. Закрытие редактора без сохранения оставляет прежние настройки. Прокрутка фона под диалогом заблокирована. Консоль без ошибок и предупреждений. Четыре локальных файла шрифтов, их MIME, GET/HEAD и закрытость посторонних путей проверены серверным тестом; `go test ./...` и `go vet ./...` проходят.
