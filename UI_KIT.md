# UI Kit MIRulesets

Все значения берутся из переменных в `web/styles.css` (`:root`). Новый цвет, радиус или длительность сначала добавляется туда и в эту таблицу, потом используется в правилах.

Визуальная основа — [UI kit MIBoard](https://github.com/blagodaren/miboard/blob/main/UI_KIT.md). Локальная реализация сохраняет структуру MIRulesets и работает без внешних ресурсов. Уведомления об авторских правах находятся в `web/licenses/`.

## Направление

| Решение | Значение |
| --- | --- |
| Характер | Точный, спокойный, технический |
| Среда | Серверная панель: нейтральные поверхности, светлая и тёмная темы |
| Акцент | Один янтарный. Отмечает конец цепочки «источники → правила → файлы», формат MRS и выбор; успешные состояния используют отдельный зелёный |
| Повторяющаяся деталь | Behavior и форматы видны рядом с каждым набором |
| Чего нет | Градиентов, свечения, цветных теней, эмодзи, декоративных иллюстраций, демонстрационных чисел |

3. Hex-значения вне `:root` запрещены.

## Темы

Режим оформления выбирается в верхней панели и на экране входа: «Системная», «Светлая», «Тёмная». По умолчанию используется системный режим; он следует настройке ОС. Выбор хранится в браузере и применяется до загрузки интерфейса. Изменение синхронизируется между вкладками, не закрывая диалоги и не меняя введённые данные. Недоступное хранилище не мешает переключению в текущей вкладке.

Палитры заданы рядом через `light-dark()` в `:root`. `data-theme="light"` и `data-theme="dark"` включают явный режим; отсутствие атрибута оставляет выбор за `prefers-color-scheme`. Компоненты используют семантические переменные без отдельных цветовых переопределений.

## Отступы и размеры

1. Сетка 4 px. Все отступы кратны 4 px.
2. Внутри группы 8–12 px, между группами 16–24 px, между секциями страницы 24 px.
3. Поля страницы: 32 px, 24 px до 1150 px, 20 px до 800 px, 16 px до 560 px.
4. Панель: 20 px, на узком экране 16 px. Вложенная карточка: 16 px. Тело диалога: 24 px, на телефоне 16 px.
5. Кнопки: 36 px обычные, 32 px для `.small`. На телефоне поля и кнопки не ниже 44 px.

Боковая панель 244 px, контент не шире 1600 px.

## Форма

| Переменная | Значение | Где |
| --- | --- | --- |
| `--radius-xs` | 4 px | Теги форматов, кнопка выбора файла |
| `--radius-control` | 10 px | Кнопки, поля, пункты навигации, уведомления |
| `--radius-inset` | 12 px | Карточка источника, блок кода, toast |
| `--radius` | 16 px | Панели, сводка сборки |
| `--radius-status` | 1 px | Квадратный индикатор состояния |
| `--shadow` | `0 8px 24px` чёрный 8 % / 50 % | Только toast |

Диалоги-панели прижаты к правому краю и не скругляются. Вложенный радиус всегда меньше внешнего. При открытом диалоге фон не прокручивается; прокручивается только его содержимое.

## Типографика

Семейства: `--font-sans` (Geist → Segoe UI → system-ui) и `--font-mono` (Geist Mono → Cascadia Code → Consolas). Четыре файла WOFF2 с латиницей и кириллицей встроены в бинарник и отдаются с этого же сервера. Внешних запросов за шрифтами нет; при их загрузке используется системная подстановка.

| Размер | Где |
| --- | --- |
| 12 px | Метаданные, подписи полей, заголовки таблиц, подсказки, теги и код |
| 13 px | Кнопки, строки таблицы, навигация |
| 14 px | Основной текст |
| 14 px | Заголовки секций и панелей |
| 16–24 px | Заголовок диалога, пустого состояния, формы входа |
| 28 px | Число в сводке |
| 28 px | `h1` страницы (44 px на экране входа) |

Правила:

1. Начертания 400 и 500. Полужирного и курсива нет.
2. Обычный регистр. Прописные с разрядкой не используются.
3. Числа, ID, URL, хеши и правила набираются `.mono` с табличными цифрами.
4. Отрицательный трекинг только у `h1` и логотипа.

Недоступная кнопка использует курсор запрета и сниженную прозрачность. Курсор ожидания появляется только при `aria-busy="true"`; подпись кнопки сообщает, какое действие выполняется.

## Логотип

Файл — `web/favicon.svg`. Его геометрия и цвета сохраняются без изменений: поле 12 × 12, скругление плитки 2,5. Знак только чёрный на белой плитке в обеих темах; не перекрашивать в акцент и не применять цветовые фильтры.

Минимальный размер — 16 px. В панели и на экране входа используется `.brand-icon`: 24 × 24 px, на ширине до 800 px — 20 × 20 px. Размер задаёт `--brand-icon-size`, отступ до названия — `--brand-icon-gap` (12 px, на узком экране 8 px). В README логотип имеет размер 64 × 64 px.

Рядом с названием изображение имеет пустой `alt`, чтобы название не повторялось для скринридера. Без текстового названия используется `alt="Логотип MIRulesets"`.

## Иконки

Контурные, набор Lucide (ISC), встроены в `web/app.js` как SVG-пути. Размер 18 px, в кнопках 16 px; толщина 1,5, цвет наследуется от текста. Расстояние до подписи 8 или 12 px.

Доступные имена: `layers`, `server`, `plus`, `search`, `refresh`, `chevron`, `arrow`, `edit`, `close`, `trash`, `download`, `copy`, `globe`, `file`, `folder`, `link`, `cloud`, `logout`, `lock`, `check`, `monitor`, `sun`, `moon`.

Иконка ставится, только если ускоряет распознавание действия. Эмодзи не используются.

## Движение

| Переменная | Значение | Где |
| --- | --- | --- |
| `--ease` | `cubic-bezier(.22,1,.36,1)` | Единственная кривая |
| `--dur-fast` | 160 мс | Наведение, фокус, toast |
| `--dur-panel` | 240 мс | Открытие боковой панели |
| `--dur-page` | 300 мс | Появление страницы |

Анимируются только цвет, фон, граница, прозрачность и `transform`. Зацикленных анимаций, увеличения при наведении и `transition: all` нет. При `prefers-reduced-motion` всё движение отключается.

## Текст интерфейса

1. Заголовок называет объект или действие: «Наборы правил», «Создать набор».
2. Без восклицательных знаков, приветствий и обещаний.
3. Без точки в конце заголовков, подписей и кнопок.
4. Ошибка сообщает причину и следующее действие.
5. Числа приходят с сервера. Примеров и заглушек в рабочем интерфейсе нет.

## Адаптив

| Ширина | Изменение |
| --- | --- |
| от 1600 px | Больше воздуха в таблице и пустом состоянии |
| до 1150 px | Уже поля, скрыты второстепенные колонки (`.hide-medium`) |
| до 800 px | Навигация становится горизонтальной полосой сверху, таблица прокручивается |
| до 560 px | Сводка 2 × 2, формы в одну колонку, поиск в отдельной строке, кнопки диалога на всю ширину |

## Проверка правки

1. В правилах вне `:root` нет hex-цветов, пикселей радиуса и миллисекунд.
2. Все отступы кратны 4 px.
3. Нет текста мельче 11 px.
4. Фокус с клавиатуры виден на каждом новом контроле.
5. Обе темы проверены на 1440 px и 390 px, консоль браузера без ошибок.

Проверка сохранения темы, ошибок хранилища и синхронизации вкладок: `node --test web/theme_test.cjs`. Для серверной части: `go test ./...` и `go vet ./...`.
